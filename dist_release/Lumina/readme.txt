Lumina 使用说明
================

1. 启动
-----
1. 保留整个 Lumina 文件夹，不要只复制 Lumina.exe。
2. 双击 Lumina.exe 启动，启动后在 Windows 系统托盘显示 Lumina 图标。
3. 点击托盘图标，或右键托盘图标选择“亮度调节”，打开控制面板。

2. 控制面板
-------
1. 上方是 Lumina 设备卡，下方是显示器亮度区。
2. 面板配置会自动保存，不需要点击保存按钮。
3. 右下角显示当前已连接的 Lumina 数量。

3. 自动旋转
-------
1. 在设备卡中选择自动旋转目标显示器。
2. 显示器坐标轴以正对屏幕为准：左到右是 X+，下到上是 Y+。
3. Lumina 外壳边缘有坐标轴丝印，设置方向时可以直接对照丝印。
4. 设置“屏幕X+”和“屏幕Y+”，把显示器方向绑定到 Lumina 当前安装后的机身方向。
5. 勾选“自动旋转”。旋转设备或显示器后，屏幕方向会按配置切换。

4. 自动亮度
-------
1. 在设备卡中勾选“自动亮度”。
2. 设置 0 档到 4 档亮度百分比；点击档位名称可调整 lux 分界点。
3. 在显示器亮度区，把目标显示器右侧下拉框选为对应 Lumina。
4. 选择“手动”时显示亮度滑杆，可直接拖动调节显示器亮度。

5. LED
------
1. 设备卡右上角红色圆点用于关闭 LED。
2. 设备卡右上角白色圆点用于打开 LED。
3. 每次点击都会立即发送一次 LED 指令，并记住状态。
4. 锁屏、休眠或睡眠前会临时关闭 LED，解锁或恢复后按记忆状态恢复。

6. 自动暗屏和自启动
-----------
1. 底部左侧输入框设置自动暗屏空闲时间，单位为秒。
2. 月亮按钮启用或暂停自动暗屏。
3. 中间按钮关闭控制面板。
4. 右侧三角按钮开启或关闭 Windows 开机自启动。

7. 常见问题
-------
1. 无法调节亮度：确认显示器支持并开启 DDC/CI，尽量减少扩展坞和转接线影响。
2. 自动旋转方向不对：重新检查“屏幕X+”和“屏幕Y+”是否与设备安装方向一致。
3. LED 点击无反应：确认设备固件支持 LED 控制，重新插拔 Lumina 后再试。
4. 程序无法覆盖更新：先退出 Lumina.exe，并关闭打开在 Lumina 文件夹中的资源管理器窗口。
